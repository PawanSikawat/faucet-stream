**Design notes for review:** bookmark is a JSON map `{capture_instance: lsn_hex}` stored under one state key (`mssql-cdc:&lt;db&gt;:&lt;capture_instance&gt;` for one instance, `mssql-cdc:&lt;db&gt;:&lt;fnv1a-digest&gt;` for many). Changes are queried with `N'all'` (op 1/2/4); commit rows are buffered by `__$start_lsn` and each committed transaction becomes its own `StreamPage` with `bookmark: Some(map)`. On resume, the next poll starts at `increment(bookmark)`. LSNs are bound via `CONVERT(BINARY(10), @P, 2)`; the capture-instance name (the only value interpolated into the `cdc.fn_cdc_get_all_changes_&lt;ci&gt;` identifier) is validated to `[A-Za-z0-9_]`. I dropped a proposed `include_before` field because in `'all'` mode it would be a no-op (deletes always carry `before`, inserts/updates carry `after`).

4. **Docker integration/conformance tests** require SQL Server with `MSSQL_AGENT_ENABLED=true` (so the CDC capture job populates change tables); they poll for capture and are CI-only on ARM Macs — they will not run in a plain `cargo test --lib`.
