I have one thing. For example, let's say I'm working with software, and the software gets a nightly release or some feature release or anything like that. In that case, the latest version gets updated because there is a new release that has come up, but I don't want my existing features and all to use that. Maybe that might be a test version, maybe that might be a feature version which is still being tested or on pre-prod staging.

Ideally, the latest should be the latest stable version. This is what I feel: the default version should be the stable version so that anybody who is using that doesn't end up failing. Whenever I have to increment something, stable becomes a mindful increment so that every other person who's using that template has a mindful release happen whenever they don't provide the version for it.

This is what I feel should be. Same with previous: I want the idea of previous to be the last stable release. What was the last stable that was specified? Maybe in the initial time there won't be any last stable, so previous would always defer to null or something like that, or it won't have any value. I only want the last stable version that was specified to be the previous. Does it make sense?
