## T-SQL decisions worth flagging

1. **`SELECT … INTO` with a `UNION ALL` derived table** to create the temp table, instead of reconstructing `CREATE TABLE` from `sys.columns`. `discover_column_types` only returns the bare system type name (`nvarchar`), and `CREATE TABLE (#k nvarchar)` defaults to **length 1** — silently truncating keys and deleting the wrong rows. `SELECT … INTO` copies the full declared type/length/precision/collation by construction. The `UNION ALL` (two `WHERE 1 = 0` legs, zero rows read) is load-bearing, not decoration: a plain `SELECT … INTO` **inherits a source column's IDENTITY property**, and the subsequent key INSERTs would then fail without `IDENTITY_INSERT`. A UNION'd column never inherits it. A test asserts the `UNION ALL` survives refactors.
2. **`#temp` (session-scoped), not `##`**, so concurrent cleanups on different pooled connections cannot collide on the name — the analogue of PostgreSQL's `ON COMMIT DROP`. Because a pooled connection outlives one cleanup, the name is dropped defensively *before* creating (outside the txn) and best-effort after COMMIT. The `OBJECT_ID(N'tempdb..#…')` guard is used over `DROP TABLE IF EXISTS` (2016+) for wider server support.
3. **Timeout/desync caveat respected**: `cleanup_in_txn` returns `Err((error, timed_out))`; on `timed_out` the ROLLBACK is deliberately skipped and the connection dropped (mirrors `insert_chunk`/`apply_plan`). On a normal error ROLLBACK undoes the loaded keys *and* drops the temp table, since T-SQL DDL is transactional.
4. **Column validation runs before the cleanup connection is checked out** — `discover_column_types` takes its own pool connection, and nesting the two would deadlock a `max_connections: 1` pool. Missing table and missing column produce distinct messages naming column + table.
5. Empty `seen` loads zero keys and falls straight through to the scope-wide `DELETE` — the motivating case, not a no-op. Overflow is not re-checked here; `run_stream` already refuses before calling (`seen_keys.overflowed()`).</result>
