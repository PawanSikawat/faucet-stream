5. **Problem Solving:**
   - Established the ordering guarantee: env/file/secret resolve *before* params bind, so caller input is never re-scanned for directives; supplied values containing `${` are rejected outright.
   - Secret-param persistence: refused on clustered servers (422) because the materialized config is persisted for peer execution and the history DB is not a secret store.
   - `resolve_version` returning concrete `u32` (and `materialize` taking `u32`) structurally eliminates the "None quietly means newest" bug class.
   - Re-launching the already-live version is a no-op, keeping `previous` a real rollback target.
   - Deleting a version cascades to channels **and** launch entries so no pointer outlives its target.
   - `TemplateStatus` and all pointers are derived from the launch log + deprecation marker, so status can never disagree with stored rows.
   - Verified the whole lifecycle live: `out-v1-b.jsonl` (unpinned after v2 registered → still v1), `out-v2-c.jsonl` (after launching v2), `out-v1-d.jsonl` (after rollback).
